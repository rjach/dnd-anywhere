## Description

Drag and drop files into any upload button, on any website.

Lots of sites only give you a "Browse…" button for uploads, so you end up hunting through a file dialog for a file that's already on your screen. DnD Anywhere turns every upload field and upload button into a drop zone while you drag files into the window.

HOW IT WORKS
• Drag files from your desktop or file manager into any tab.
• Drop zones appear on the page's upload fields, labeled with what they accept.
• Drop. The site receives your files exactly as if you'd picked them in the file dialog.

WORKS WITH
• Styled "Upload", "Attach" and "Browse…" buttons that hide the real file field
• Upload buttons that create their file picker on click
• Web components (shadow DOM) and embedded forms (iframes)
• React, Vue and other web apps
• Respects which file types a field accepts and whether it takes one file or several
• Sites with their own drag and drop are left alone (hold Alt to use DnD Anywhere's zones anyway)

PRIVATE BY CONSTRUCTION
• Zero network requests. The extension never sends anything anywhere.
• No data collection: no analytics, no tracking, no account.
• Only one permission (storage) for your settings.
• Free and open source (MIT). The published code is not minified, so you can read exactly what runs.

WHY "READ AND CHANGE ALL YOUR DATA ON ALL WEBSITES"?
Upload fields can be on any site, so a small script must be present on every page to find them. It does nothing until you drag files into the window, and it doesn't read or send page content.

Turn it off for any site with one click on the toolbar button.
