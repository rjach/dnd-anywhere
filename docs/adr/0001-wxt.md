# 0001. Build with WXT

- Status: Accepted
- Date: 2026-10-04

## Context

We need Manifest V3 builds for Chrome, Edge and Firefox from one codebase, a MAIN-world content script, a fast dev loop, and release zips (including a Firefox sources zip). Options: hand-rolled Vite/esbuild config, Plasmo, CRXJS, WXT.

## Decision

Use [WXT](https://wxt.dev). It generates per-browser manifests from entrypoint metadata, supports `world: "MAIN"` and `matchOriginAsFallback`, opens a browser with the extension loaded in dev, and wraps zipping and store submission (`wxt zip`, `wxt submit`).

The content script uses no UI framework. Popup, options and welcome pages use Preact for small bundles and React-like familiarity.

## Consequences

- Contributors need only `pnpm dev`.
- We depend on WXT's release cadence; its config is small, so moving to plain Vite later would be contained.
- Builds are deliberately not minified (`build.minify: false`) for reviewability; the size budget applies to that output.
