# Getting help

- **How do I…? / Is it supposed to…?** Start with the [support page](https://rjach.github.io/dnd-anywhere/support/), then ask in [GitHub Discussions](https://github.com/rjach/dnd-anywhere/discussions).
- **A site doesn't work.** Use "Not working here? Report this site" in the toolbar popup, or the [site report form](https://github.com/rjach/dnd-anywhere/issues/new?template=site_not_working.yml).
- **Something is broken.** Open a [bug report](https://github.com/rjach/dnd-anywhere/issues/new?template=bug_report.yml).
- **An idea.** Open a [feature request](https://github.com/rjach/dnd-anywhere/issues/new?template=feature_request.yml) or start a discussion.
- **A security problem.** Follow [SECURITY.md](SECURITY.md). Don't open a public issue.
- **Anything else:** [hello@rojanacharya.com](mailto:hello@rojanacharya.com).

DnD Anywhere is maintained by volunteers. There is no paid support, but every report is read. Issues are public, so please don't include private links, personal information or file contents.
